# SHMUP Reborn — Support

## English

Write to **cabbry@icloud.com**: a question, a bug, a suggestion. Please say
which device you play on, its iOS version, and the game's version (shown on
the home screen).

If you have a GitHub account, you can also open an issue at
<https://github.com/cabbry/Shmup/issues>.

## Français

Écrivez à **cabbry@icloud.com** : une question, un bug, une suggestion.
Précisez l'appareil sur lequel vous jouez, sa version d'iOS et la version du
jeu (affichée sur l'écran d'accueil).

Si vous avez un compte GitHub, vous pouvez aussi ouvrir un ticket sur
<https://github.com/cabbry/Shmup/issues>.
